Browsable index of **existing** JSDoc / TSDoc / file headers in the monorepo.

Missing docs show as "No docstring in source" — nothing is invented here.

## Sections

- **Web Legos** — shared React components, layouts, and API helpers
- **Server Legos** — Express modules (`siteText`, `siteHealth`, mail deprecations, …)
- **Site assets** — per-app exports under `client/src/components` (not shared legos). Each site page lists every export as an asset.

Live demos are allowlisted for presentational pieces only (no Firebase).
